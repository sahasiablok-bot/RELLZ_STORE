# RELLZ STORE — Saluran & Kontak

Website ini hanya menampilkan profil toko, tautan saluran/komunitas, dan nomor kontak. Tidak ada katalog jual beli atau tampilan akun game.

## Sebelum deploy
Di `index.html`, cari `href="#" data-placeholder` dan ganti `href="#"` dengan tautan asli saluran WhatsApp, grup, atau media sosial. Nomor admin saat ini `628818375778`.

## Deploy
1. Ekstrak ZIP ini.
2. Upload `index.html`, `vercel.json`, dan folder `assets` beserta `logo.png` ke root repository GitHub.
3. Pastikan `index.html` berada langsung di root repository.
4. Buka https://vercel.com/new, import repository, pilih preset **Other**, lalu deploy.
